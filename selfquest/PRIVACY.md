# 自律勇者（SelfQuest）隐私政策

最后更新：2026-10-12

> 本文件是 `privacy.html` 的 Markdown 存底，内容以 `privacy.html` 为准。App Store Connect 里填的是 HTML 那一份。

## 摘要

自律勇者不收集任何数据。没有账号，没有服务器，App 也不发起任何网络请求。
你的习惯、打卡、专注记录只写在这台设备的沙盒里。

这一句是可核对的：工程里没有链接任何网络框架，二进制里没有任何网络符号，代码里字面写死的网址一共只有三个——
关于页里的隐私政策、使用帮助和反馈入口，它们是交给系统浏览器打开的，App 自己不会去请求。
飞行模式下全部功能可用，包括第一次启动。

## 我们处理什么、存在哪

| 数据 | 用途 | 位置 |
|---|---|---|
| 习惯的名称、图标、颜色、重复方式 | 展示今日待办 | 设备沙盒 Application Support |
| 打卡记录（日期、当次获得的经验与金币） | 连击计算、统计、热力图 | 设备沙盒 |
| 专注记录（任务名、时长、是否完成） | 专注统计与柱状图 | 设备沙盒 |
| 角色状态（经验、金币、已购装备、已解锁成就） | 等级与装备展示 | 设备沙盒 |
| 偏好设置（默认专注时长等） | 恢复上次的使用状态 | 设备沙盒 |

以上数据全部在本机读写，不会离开设备。

具体来说，全部内容放在一个文件里：`Application Support/SelfQuest/database.json`。
它是**未加密的纯文本 JSON**，任何能读到这台设备文件系统的人都能直接看懂。
App 不使用系统设置（UserDefaults）、钥匙串，也不使用 iCloud 或任何云同步。

## 你亲手写的文字

习惯名称和专注任务名是**你自己输入的原文**，会原样存进上面那个文件。
打卡的日期、专注的时长与时间点也一并保存。这些是这台设备上唯一与你有关的个人内容。

## 网络

App 不发起任何网络请求。飞行模式下全部功能可用。

需要说明一处：设置里的「关于」卡片有三个链接（隐私政策、使用帮助、反馈问题）。
点它们时，App 把网址交给系统，由 Safari 打开——**请求由 Safari 发出，不是这个 App 发出的**。
不点就不会有任何网络行为。

## 权限

**App 不申请任何权限。** 没有通知、没有相机、麦克风、相册、通讯录、位置、健康数据、运动与健身，
也没有 Face ID。工程里一个权限说明字段都没有写。

其中「没有通知权限」值得单独说一句：这是一个习惯打卡 App，很多人会默认它会提醒你打卡。
**它不会。** 它从来没有请求过通知权限，也不会在后台唤起。

## 你对自己的数据有完全控制

设置页提供两种导出：JSON 是完整存档，CSV 是打卡明细，可用 Excel 打开。
两种都通过系统分享面板交给你选择的目标应用，**只有你主动点导出才会发生**，
App 不知道也不记录你发给了谁。

**导出是单向的，请务必读完这一段。**
**这个版本没有导入功能。** 导出的 JSON 不能被读回 App 里，App 里也没有「从文件恢复」的按钮，
也没有在系统里注册成 JSON 文件的打开方式。

### 换手机怎么办

把导出的 JSON 存档留好，它是完整的记录，能在电脑上或任何文本编辑器里查看；
但**带着这份文件并不能在新手机上把 App 的记录变回原样**。
新手机上重新添加习惯、重新开始，是目前唯一可行的做法。上架前这条会改；在那之前，这句就是它的真实状态。

### 导出文件留在哪

导出的 JSON 和 CSV 先写进 App 的临时目录，再交给系统分享面板。
**分享完成后 App 不会删掉这份副本**，它会留在临时目录里直到系统回收。想立刻清掉，删除 App 最干净。

## 我们不做的事

- 不要求注册或登录
- 不收集姓名、邮箱、位置、设备标识符
- 不接入广告、分析或追踪 SDK
- 不读取通讯录、麦克风、摄像头、健康数据
- 不把你的数据共享给任何第三方

## 数据删除

删除 App 即可清除全部数据。也可以在 App 内逐个删除习惯——删除时会一并清掉它的打卡记录。

还有一处要知道：如果存档文件损坏、读不出来，App 不会删掉它，而是把它改名留一份在旁边
（`database.json.corrupt-` 加一个时间戳）。
**这些副本不会被 App 里的任何操作清除，只有删除 App 才会一起消失。**
