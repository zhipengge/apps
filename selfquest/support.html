中文

怎么开始？

第一次打开会有三个示例习惯（早起 / 背单词 / 运动）。点一下圆圈就打卡，当天全部完成会显示「今天全勤，收工」。

连击是怎么算的？

只数排期内的日子。工作日习惯跳过周末不算断，周末习惯跳过工作日同理。今天还没打卡不会把连击清零——从昨天往前数。

经验、金币有什么用？

经验涨等级，金币在「角色」页买装备。连击越长，单次打卡给的经验金币越多，但加成封顶 2 倍。

番茄钟中途放弃会怎样？

专注满 5 分钟才有收益。中途结束按 40% 折算经验，且不给金币——完成才给全额。

为什么习惯只能归档不能直接删？

两个都能做。归档会保留历史打卡，适合「暂时不做」；彻底删除会连打卡记录一起清掉，统计里也就没有这条了。编辑页里两个按钮都给了。

换手机怎么迁移？

在「设置 → 数据」里导出 JSON 备份，在新设备上用文件导入。数据不会自动上云。

数据存在哪？

只在这台设备上。详见隐私政策。

怎么反馈问题？

到 GitHub Issues 提交。

English

Getting started

Three sample habits ship with the first launch (wake early, vocabulary, exercise). Tap the circle to check in. Finish everything due and the header says you are done for the day.

How are streaks counted

Only scheduled days count. A weekday habit skips the weekend without breaking, and vice versa. Not having checked in yet today will not reset your streak; it counts back from yesterday.

What do XP and gold do

XP raises your level, gold buys equipment on the Character tab. Longer streaks increase the reward per check-in, capped at double.

What if I stop a focus session early

You need at least five minutes for any reward. Stopping early pays 40 percent of the XP and no gold. Completing pays in full.

Why archive instead of delete

Both are available. Archiving keeps the check-in history, which suits a habit you are pausing. Deleting removes the history too, so it disappears from statistics. The editor offers both.

Moving to a new phone

Export the JSON backup from Settings, then import it on the new device. Nothing syncs to the cloud automatically.

Where is my data

Only on this device. See the Privacy Policy.

Reporting a problem

File an issue at GitHub Issues.
