# 自律勇者

把坚持做成一个有角色、有等级、有装备的游戏。

## 这是什么

自律勇者是一个游戏化的自律工具。

打卡和专注都会给经验与金币。经验涨等级，金币买装备，装备穿在角色身上。全部数据只落本机 JSON，**没有账号，App 也不发起任何网络请求**。

它不做排行榜，也不做社交压力——你只需要对付昨天的自己。

## 功能

- **习惯打卡**：自定义图标颜色，每天 / 工作日 / 周末三种重复方式
- **连击系统**：连续打卡天数，加成封顶 2 倍金币
- **番茄钟**：四种预设时长 + 不限时正计时，完成与放弃分别结算
- **角色养成**：经验等级、金币、9 件装备分三个槽位、11 个成就
- **统计**：打卡热力图、打卡率、专注柱状图、习惯排行
- **导出**：JSON 完整备份 + CSV 打卡明细

## 系统要求

- 平台：iOS 17.0 及以上（iPhone 与 iPad）
- 最低系统：**iOS 17.0**
- 中文界面

## 常见问题

**怎么开始？**
首次打开有三个示例习惯。点一下圆圈就打卡，当天全部完成会显示「今天全勤，收工」。

**连击怎么算？**
只数排期内的日子。工作日习惯跳过周末不算断。今天还没打卡不会清零，从昨天往前数。

**番茄钟中途放弃会怎样？**
专注满 5 分钟才有收益。中途结束按 40% 折算经验且不给金币，完成才给全额。

**为什么习惯有归档和删除两种？**
归档保留历史打卡，适合「暂时不做」；彻底删除会连记录一起清掉。编辑页两个按钮都给了。

**换手机怎么迁移？**
设置页导出 JSON 备份，新设备上导入。不会自动上云。
