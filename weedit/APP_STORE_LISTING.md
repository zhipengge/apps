## 2. 描述 (Description)

> **上限 4000 字符**

### 简体中文

```
文辑是写给公众号、小红书、知乎、微博的本地图文编辑器。同一篇稿切到不同平台，会改成对方编辑器吃得下的 HTML 或纯文本，复制后到网页后台粘贴。

【为什么是复制而不是一键发布】
这些平台没有给第三方使用的稳定发文接口。文辑不登录你的账号，也不代发，避免格式被接口丢掉，也避免把稿件传到别人的服务器。

【编辑】
- 正文、标题、加粗斜体、颜色、引用、列表
- 图片、表格、视频和音频（视频音频在多数平台需到后台单独插入，复制时会留下说明，避免裂开）
- 文稿保存在本机沙盒，关闭窗口即退出

【四个平台】
- 公众号：内联样式、677 宽版心、表格边框、图片随 HTML 带上
- 小红书：标题字数提示、表格改成文字、图片写入剪贴板
- 知乎：保留标题层级和表格，一级标题转为二级
- 微博：纯文本加图片，超字数会提示

不收集数据，没有账号，没有分析 SDK。
```
**字符数：约 420 / 4000**

### English

```
WeEdit is a local rich-text editor for WeChat Official Accounts, Xiaohongshu, Zhihu, and Weibo. One draft is rewritten into HTML or plain text each editor can paste.

[Why copy instead of one-click publish]
Those sites do not offer a stable third-party publishing API. WeEdit never logs into your accounts and never uploads drafts.

[Editing]
- Headings, emphasis, color, quotes, lists
- Images, tables, video and audio (most platforms require media to be inserted in their own editor; WeEdit copies a placeholder instead of a broken player)
- Drafts stay in the sandbox; closing the window quits the app

[Platforms]
- WeChat Official Accounts: inline CSS, 677px column, bordered tables, images in HTML
- Xiaohongshu: title length hints, tables flattened, images on the pasteboard
- Zhihu: headings and tables kept, h1 mapped to h2
- Weibo: plain text plus images, with length warnings

No accounts, no analytics, no tracking.
```
**字符数：约 780 / 4000**
