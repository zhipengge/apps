# 文辑 — 用户说明

本地写稿，按公众号、小红书、知乎、微博的规则复制出去粘贴。稿件只存在你这台 Mac 上。

## 能做什么

- 一篇稿里写文字、插图片、表格、视频和音频
- 切换平台后，右侧会告诉你哪些能粘贴、哪些得到后台补
- 「复制并打开后台」：把适配过的 HTML / 纯文本放进剪贴板，并打开对应网站的编辑页
- 视频和音频多数平台不允许随正文粘贴，会留下说明，避免到了后台变成空白

这些平台没有给第三方用的稳定一键发布接口，所以文辑不登录你的账号，也不代发。

## 怎么用

1. 左边新建文稿，中间写
2. 顶上选平台
3. 点「复制并打开」
4. 在打开的网页编辑器里粘贴（Command+V）

## 常见问题

**粘贴后图片没了？**  
先确认复制的是「适配稿」而不是只选中了纸张里的字。公众号后台有时会丢掉过大的内嵌图，可以先把图缩小再插。

**为什么不能直接点发布？**  
对方不提供给第三方 App 用的发文接口。打开后台粘贴是目前能保持格式的办法。

**数据在哪？**  
本机沙盒容器。删 App 并去掉 `~/Library/Containers/com.gezhipeng0201.WeEdit` 即无残留。

## FAQ (English)

WeEdit keeps drafts on your Mac and copies platform-tuned HTML or plain text so you can paste into WeChat Official Accounts, Xiaohongshu, Zhihu, or Weibo. There is no account and no remote publishing API.

Support: GitHub Issues on the apps site.
