牧云电视 — 帮助与支持

Muyun TV · Support · 2026-08-28

牧云电视是直播流播放工具。导入你自己的 M3U、JSON 或 TXT 播放列表，或手动添加地址后播放。 本应用不提供、不托管任何电视节目。源的合法性由你负责。

能做什么

  • 从文件或网址导入 M3U / M3U8 / JSON / TXT 播放列表。
  • 手动添加单条直播源；按分组浏览、搜索、收藏、编辑、删除。
  • 全屏播放 HLS 和常见 HTTP 视频流；支持画中画和 AirPlay。
  • 中文 / English；深色、浅色或跟随系统。
  • 导出 JSON 备份。清空列表后不会自动填回。

怎么开始

  1. 打开 App。首次是空列表，这是正常的。
  2. 点右上角加号，进入「导入直播源」。
  3. 可点「一键导入源」，从本页同目录的 public_channels.m3u 拉取公开测试流（苹果 / Mux / Akamai 等测试地址，不是电视节目）。
  4. 也可以粘贴播放列表网址，或从「文件」选择 M3U / JSON / TXT。还可以只填名称和地址添加一条。
  5. 在列表里点频道即可播放。左滑编辑或删除，右滑收藏。

空状态里的「一键导入测试源」与导入页的一键导入是同一份列表。

导入格式

  • M3U：标准 #EXTINF 行，可带 group-title 和 tvg-logo。
  • JSON：对象数组，字段为 name、url，可选 group、logo。
  • TXT：每行 名称,地址，也可用竖线或制表符分隔。

默认合并导入，按地址去重，不覆盖已有频道的名称。打开「覆盖现有列表」则会整份替换。

常见问题

为什么打开是空的？

本应用不内置频道。需要先导入播放列表或手动添加源。

清空后再打开，会不会自动恢复示例？

不会。空列表会保持为空。

某个源无法播放

常见原因：地址失效、源站限制客户端、当前网络访问不到、或格式不受系统播放器支持。请检查地址，或换一条源。

为什么允许非 HTTPS？

不少直播源仍使用明文 HTTP。流量发往你添加的源站，不经过我们的服务器。详见 隐私政策。

这是 IPTV 运营或节目提供方吗？

不是。只是播放工具。请只导入你有权使用的源。侵权或违规可通过 App 内关于页举报。
