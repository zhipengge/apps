# 牧云电视 / Muyun TV

牧云电视是 iOS 上的直播流播放工具。导入你自己的 M3U、JSON 或 TXT 播放列表，或手动添加地址后播放。应用不提供、不托管任何电视节目。源的合法性由你自行负责。

商店名：**牧云电视**（设备上同样显示为「牧云电视」）

- 隐私政策：<https://zhipengge.github.io/apps/muyuntv/privacy.html>
- 支持页：<https://zhipengge.github.io/apps/muyuntv/support.html>
- 商店文案：见 `APP_STORE_LISTING.md`

## 能做什么

- 从文件或网址导入 M3U / JSON / TXT 播放列表
- 手动添加单条直播源；可按分组浏览、搜索、收藏
- 播放 HLS 和常见 HTTP 视频流；支持画中画和 AirPlay
- 中文 / English，深色 / 浅色 / 跟随系统
- 导出 JSON 备份；清空列表后不会自动填回

## 使用

1. 打开 App，点右上角加号进入「导入直播源」。可点「一键导入源」拉取公开列表：央视网公开音频（无画面）、CGTN / France 24 / DW 等播出方公开的国际频道，以及厂商测试流。
2. 也可以粘贴播放列表网址，或从文件选择 M3U / JSON / TXT。还可以只填名称和地址添加一条。
3. 在列表里点频道即可全屏播放。左滑可编辑或删除，右滑收藏。
4. 设置里可改语言和主题。关于页有免责声明和举报入口。

演示频道是苹果公开的 HLS 测试流，只用来确认播放器能工作，不是电视节目。

## 隐私

频道列表只存在本机。联网只为拉取你指定的播放列表和播放那些流。详见 `PRIVACY.md`。

## FAQ

**为什么打开是空的？** 本应用不内置频道。需要先导入播放列表。

**清空后再打开会不会自动恢复示例？** 不会。

**某些源无法播放？** 常见原因：地址失效、源站限制客户端、网络无法访问、或格式不受系统播放器支持。可换源或检查地址。

**这是 IPTV 运营平台吗？** 不是，只是播放工具。
