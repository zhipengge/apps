首次发布：常驻菜单栏的网络诊断。分五层排查物理连接、局域网网关、DNS 解析、公网出口和关键节点，明确告诉你这次断在哪一层，而不是笼统地说网断了。网关不回应 ICMP 但公网直连是通的时候，网关会判为通并附说明，不冤枉它；物理层不通时后面四层标为未检测，不写成不通。ICMP 被屏蔽时改用 TCP 兜底，连接被拒绝同样证明主机活着。导出一份纯文本报告给 IT，或一段排版好的短文本直接发在聊天里。只诊断不修改：工程里不允许出现任何写系统网络配置的 API，这条由脚本每次跑测试机械检查。对外只有三种只读动作，不带账号、不带设备标识符、不带任何业务数据，也不向任何服务器回传。不需要任何系统权限。需要 macOS 13.0 或更高版本。

---

First release: a network diagnostic that lives in the menu bar. It checks five layers, the physical link, the local gateway, DNS resolution, the public internet and key nodes, and tells you which one broke rather than saying the network is down. When a gateway ignores ICMP but the direct public connection works, it is reported as healthy with a note instead of being blamed; when the physical layer is down, the four layers after it are marked not tested rather than failed. If ICMP is blocked it falls back to TCP, and a refused connection still proves the host is alive. Export a plain-text report for IT, or a short formatted block you can paste into a chat. It diagnoses and never modifies: no API that writes system network configuration is permitted in the project, and a script checks that mechanically on every test run. Three read-only outbound actions only, carrying no account, no device identifier and no application data, and reporting nothing to any server. No system permissions are requested. Requires macOS 13.0 or later.
