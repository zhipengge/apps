# SpinCourt - 野球场分拨助手

一款专为野球场设计的智能分拨应用，帮助玩家快速、公平地组队对战。

## 功能特点

- 🎯 **智能分拨**：自动将参与者随机分配到不同战队
- 🎨 **视觉化展示**：精美的圆盘视图，清晰显示分拨结果
- 🎲 **随机分组**：每次分拨都会产生新的随机组合，确保公平性
- 📱 **完美适配**：支持iPhone和iPad，适配不同屏幕尺寸
- 🏆 **战队标识**：每个战队有独特的颜色和名称（烈焰、雷霆、风暴等）
- 📊 **场次编号**：清晰显示每场比赛的战队编号

## 系统要求

- iOS 18.0 或更高版本
- 支持 iPhone 和 iPad

## 使用方法

1. **设置人数**：在"参战人数"中输入参与分拨的总人数（2-25人）
2. **设置战队数**：在"战队数量"中选择要分成的战队数量（2-总人数的一半）
3. **生成分拨**：点击"开始分拨"按钮，系统会自动随机分配
4. **查看结果**：圆盘会显示分拨结果，每个指针代表一个参与者，颜色代表所属战队
5. **重新分拨**：可以多次点击"开始分拨"按钮，每次都会产生新的随机分组

## 设计说明

- 圆盘上编号1的参与者始终指向手机底部（6点钟方向）
- 其他参与者按编号顺序顺时针均匀分布
- 每个战队用不同的颜色标识，便于区分
- 底部显示所有战队的详细信息，包括组编号和人数
