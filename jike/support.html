常见问题 / FAQ

按 F12 没反应？

笔记本请按 Fn+F12。若仍无效，到「系统设置 → 键盘 → 键盘快捷键」检查 F12 是否被占用。

为什么快捷键是 Ctrl 不是 Cmd？

为了和 Linux 下的 Guake 一致。新建标签是 Ctrl+Shift+T，拷贝是 Ctrl+Shift+C。Command 对应 Guake 的 Super 键。

为什么没有进 Mac App Store？

下拉终端必须运行真实本地 Shell。App Store 要求沙盒，沙盒里伪终端几乎不能用。即刻与系统「终端」、iTerm 一样不启用沙盒，走公证分发。

标签标题从哪来？

自定义名称优先；否则读当前目录的 .guake.yml 或 .jike.yml（title: 字段）；再否则用终端标题或目录名。

怎么用 URL 控制窗口？

在终端或脚本里执行 open 'jike://toggle' 可呼出/收起。也支持 new-tab、execute、hide、show 等命令，详见产品 README。

卸载后会残留什么吗？

从「应用程序」删除 App，并移除 ~/Library/Preferences/com.gezhipeng0201.JiKe.plist 即可。

English

JiKe is a Guake-style drop-down terminal for macOS. Support is provided via GitHub Issues.

  • Open a new issue with the title prefix [即刻] or [JiKe].
  • Include macOS version, app version, steps to reproduce, and screenshots if possible.
  • On a laptop the toggle hotkey is Fn+F12. If nothing happens, check Keyboard Shortcuts in System Settings for an F12 conflict.
