# 牧云宝宝记 / MuyunBaby

牧云宝宝记是给父母和看护人用的本地育儿手账。喂奶、排便、睡眠、辅食、身高、体重、体温都能记；也可以按自己的观察习惯增加类型和分级字段。没有账号，没有云，没有广告。换机靠导出备份。

商店名：**牧云宝宝记**（设备上显示为「宝宝记」）

## 能做什么

- **随手记**：首页大按钮一键打开对应类型；发生时间默认为现在，事后可改。
- **喂奶**：亲喂、瓶喂母乳、配方奶、混合。亲喂可记左右时长；奶量可手填，留空则按当天平均或日龄估算。
- **排便**：大便 / 小便可分级展开，便血后再选程度。字段结构可改。
- **成长与日常**：睡眠、辅食、体重、身高、体温。
- **多宝宝**：分开记账，互不串记；设置里左滑删除。
- **图表**：分类型或整合；同单位曲线可叠图；横轴支持日期、月龄、出生天数；一键长图分享，水印默认可关。
- **自定义**：小数、整数、时长、文字、是否、枚举、分组；枚举选项可再挂子字段。
- **只在本机**：不申请网络或相册；备份走系统文件面板。

## 使用

1. 首次打开会有示例宝宝「安心」和一段喂奶记录，方便先看图表。不需要可在设置里删除，删掉后不会再出现。
2. 添加自己的宝宝时需填写名字和出生日期。首页左上角切换。
3. 在「记录」页点类型记一笔。亲喂奶量可手填；留空时界面会说明估算来源。
4. 「图表」可看单一类型，也可切到「整合」。右上角生成长图分享，默认带「宝宝记」水印，可关掉。
5. 「设置」管理宝宝、自定义类型、导入导出。

## 隐私

不收集、不上传、不把记录发到任何服务器。分享长图只走系统分享面板，不申请相册权限。详见 `PRIVACY.md`。

## FAQ

**换机怎么办？** 旧机导出 JSON，新机用「整份替换」导入。两台都记过可用按编号合并。

**删掉「安心」或删光宝宝再打开，会不会自动建一个？** 不会。示例宝宝只在从未删除过时出现；删掉后不会再种回来。

**亲喂不填奶量会怎样？** 先用当天其他已填奶量的平均值；当天没有参考时，按日龄估算（1 天 10 ml，之后递增，最多 120 ml）。界面会提示估算来源。图表按同一规则处理。

**分享长图会不会上传或读相册？** 不会。图片在本机生成，经系统分享面板发给你选择的对象。

**内置类型改乱了？** 设置里的记录类型可以补回缺失项，或重置内置类型；你自己新建的类型会保留。

**这是医疗产品吗？** 不是，只做记录和统计。亲喂估算奶量仅供参考。
