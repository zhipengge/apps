中文

在 iPhone 和 iPad 上通过 SSH 连接你的服务器。服务器信息与密码保存在本机钥匙串，不上传任何服务器。

上手

  • 点右上角「+」新建服务器，填写主机、端口、用户名和认证方式
  • SSH 默认端口是 22；不少云主机改过端口，填之前先确认
  • 支持密码与 SSH 密钥两种认证方式
  • 连接后可直接使用终端，支持标签页同时连多台服务器

常见问题

连接失败，提示用户名或密码错误

先确认用户名与密码能在电脑上用同一台服务器登录成功。如果密码里有特殊字符，检查是否被输入法替换成了中文标点。使用密钥登录时，确认导入的是私钥而不是公钥。

连接超时

常见原因是服务器防火墙没有放行你的当前网络，或者主机地址填错。确认端口是否正确；部分云服务商默认只开放 22 端口给白名单 IP。

输入命令后没有任何反应

先按一次回车，看提示符是否回来。如果卡住，可能是上一条命令在等待输入（比如 sudo 的密码提示）。也可以断开重连。

中文显示乱码，或部分字符变成方块

多是服务器端的 locale 设置问题。在服务器上执行 locale 确认是否为 UTF-8。也可以在应用设置里切换等宽字体试试。

横竖屏切换后内容会消失吗

不会。会话在后台保持，旋转屏幕后会恢复完整的历史输出。

我的密码会上传到云端吗

不会。密码保存在本机钥匙串，只在你发起连接时用于该次 SSH 握手。我们没有服务器，也不收集任何数据。详见隐私政策。

切换主题后旧的输出颜色没变

主题只影响之后的输出。已经渲染过的内容保留原配色，清屏或重连后统一。

支持密钥登录吗

支持。在新建或编辑服务器时选择「密钥」认证方式，导入私钥即可。

支持端口转发、SOCKS 代理或文件传输（SFTP）吗

当前版本聚焦于交互式终端，上述功能尚未提供。

iPad 上支持外接物理键盘吗

支持。蓝牙或妙控键盘连接后可直接输入。常用的组合键（如 Ctrl+C）会正确传递到远端。

启动后看到的示例服务器去哪了

示例仅用于演示界面，删除后不会自动恢复。

升级 App 会清空我的数据吗

不会。服务器列表和凭证保存在本机，升级应用不影响。建议重要服务器信息自行另外备份一份。

反馈问题

请到 GitHub Issues 提交，并附上：iOS 版本、设备型号、服务器系统版本，以及问题的具体现象。请不要在 issue 里粘贴真实的密码或私钥。

English

Connect to your servers over SSH from iPhone and iPad. Host details and passwords stay in the device keychain. Nothing is uploaded to us.

Getting started

  • Tap + to add a server: host, port, username, and authentication method
  • The default SSH port is 22. Many cloud hosts use a different one, so check first
  • Password and SSH key authentication are both supported
  • Tabs let you keep several sessions open at once

FAQ

Connection fails with a wrong username or password error

First confirm the same credentials work from a computer. If the password contains special characters, check that the keyboard did not substitute full-width punctuation. For key authentication, make sure you imported the private key, not the public one.

Connection times out

Usually the server firewall is not allowing your current network, or the host is wrong. Verify the port. Many cloud providers only allow port 22 from whitelisted IPs by default.

Nothing happens after I type a command

Press Return once and see whether the prompt returns. If it hangs, the previous command may be waiting for input, such as a sudo password prompt. You can also disconnect and reconnect.

Chinese text is garbled or shows as boxes

Usually the server locale. Run locale on the server and confirm it is UTF-8. You can also try a different monospaced font in the app settings.

Does rotating the device lose my scrollback

No. The session is kept in the background and the full history is restored after rotation.

Are my passwords uploaded anywhere

No. They are stored in the device keychain and used only for that SSH handshake. We run no servers and collect no data. See the Privacy Policy.

Old output keeps its colours after I change the theme

The theme applies to new output. Already-rendered content keeps its original colours; clear the screen or reconnect to unify it.

Is key authentication supported

Yes. Choose the key method when adding or editing a server and import your private key.

Port forwarding, SOCKS proxy, or SFTP

The current version focuses on interactive terminal sessions. Those features are not available yet.

External keyboard on iPad

Supported. Bluetooth and Magic Keyboard input works directly, and key combinations such as Ctrl+C are passed through to the remote host.

Where did the sample servers go

They exist only to demonstrate the interface. Once deleted they are not restored.

Will updating the app erase my data

No. The server list and credentials live on your device and survive updates. We still recommend keeping your own record of important host details.

Reporting a problem

File an issue at GitHub Issues with your iOS version, device model, the server OS version, and what happened. Never paste real passwords or private keys into an issue.
