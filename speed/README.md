# 速闻

每天一期，十二条到二十条值得看的新闻。

## 这是什么

速闻是一个中文新闻阅读器。每天一期，每期由编辑挑选 12 到 20 条新闻，分成科技、政治、军事、财经、娱乐五个板块。

每条新闻都能独立阅读、收藏和分享，不需要通读整期。

## 功能

- **每日一期**：按日期浏览，可回看往期
- **独立条目**：每条新闻有自己的标题、简介、正文和出处
- **五个板块**：科技、政治、军事、财经、娱乐
- **收藏**：收藏单条新闻，跨期保留
- **分享**：生成适合微信的图文文稿，也可分享单条链接
- **离线缓存**：先展示本地缓存，再静默拉取更新
- **备份**：收藏与设置可导出导入，换手机不丢

## 系统要求

- 平台：iOS 17.0 及以上（iPhone 与 iPad）
- 最低系统：**iOS 17.0**
- 需要网络连接以获取当日内容
- 中文界面

## 内容从哪来

内容每天更新，发布在项目的公开仓库里。应用启动时会拉取最新一期，同时保留本地缓存以便离线阅读。

内容由编辑流程产出，不是应用内生成的。

## 常见问题

**看不到今天的内容？**
检查网络连接。内容发布时间约为每天中午 12 点，在此之前打开会显示上一期。

**能离线看吗？**
已缓存的期次可以离线阅读。收藏的内容会一直保留在本地。

**怎么分享到微信？**
在新闻详情页点分享，选择「微信文稿」，生成的图文可直接粘贴到微信对话框或公众号。

**收藏会丢吗？**
收藏保存在本机。换手机前请先在「我的」页导出备份，在新设备上导入。

**为什么只有五类新闻？**
速闻定位是「一天里值得知道的几件事」，不做全品类资讯。板块保持稳定，方便按兴趣跳读。

## 隐私

速闻不收集你的阅读记录，不需要账号。网络请求只用于拉取公开的新闻内容。
