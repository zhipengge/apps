中文

看不到今天的内容？

先检查网络。每期末尾时间约为当天中午 12 点（东八区），在此之前打开显示的是上一期。也可以下拉手动刷新。

能离线看吗？

已缓存的期次可以离线阅读，收藏的条目会一直保留在本地。

怎么分享到微信？

进入新闻详情页，点分享按钮，选择「微信文稿」。生成的图文可以直接粘贴到微信对话框或公众号后台。

怎么回看往期？

在「速闻」页顶部切换到往期日期即可。已经缓存过的期次打开更快。

收藏会丢吗？

收藏保存在本机，卸载应用或换手机会丢失。请先在「我的」页导出备份，在新设备上导入。

某条新闻的图片打不开？

图片由内容中标注的公开图源提供，源站临时不可用时会显示占位。文字内容不受影响。

怎么反馈问题？

到 GitHub Issues 提交，附上期次日期和具体条目。

English

Today's issue is not showing

Check your connection first. Each issue is published around noon China time; before that you will see the previous one. Pull to refresh to force a check.

Can I read offline

Cached issues work offline, and bookmarked articles stay on the device.

How do I share to WeChat

Open an article, tap share, and choose the WeChat document option. The generated text can be pasted straight into a chat or an official account editor.

How do I read past issues

Switch the date at the top of the main tab. Issues you already opened load faster.

Will I lose my bookmarks

Bookmarks are stored on the device, so uninstalling or switching phones will lose them. Export a backup from the Profile tab first, then import it on the new device.

Some images do not load

Images come from the public sources cited in each article. If a source is temporarily unavailable you will see a placeholder; the text is unaffected.

Reporting a problem

File an issue at GitHub Issues with the issue date and the article in question.
