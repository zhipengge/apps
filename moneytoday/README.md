## 一句话产品说明

不限档案个数，每人可选税前 / 税后（个税 + 五险一金个人部分），
额外收入（奖金、红包、副业）整笔落当天；天 / 周 / 月 / 年四视图曲线，
背景 112 条吉言可点爆成金币，音效两处各三档可选，锁屏小组件看今日金额，
支持截图、存相册与 5 秒动图。0 联网、0 统计、0 内购，数据全在本机。
