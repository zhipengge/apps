## 一句话产品说明

最多 5 人建档，每人可选税前 / 税后（个税 + 五险一金个人部分），
天 / 周 / 月 / 年四视图增长曲线，计数区间可组合，支持截图与动图分享。
0 联网、0 统计、0 内购，数据全在本机。
