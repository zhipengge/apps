## 2. 描述 (Description)

> **上限 4000 字符**。修改需提交新版本审核。

```
今日已赚把「今天赚了多少钱」变成一个每秒都在跳的数字。

打开就是今天已经到手的钱，不用心算，也不用等工资条。适合自己看，也适合几个人一起比。

【多人建档，互不干扰】
- 最多 5 位用户各自建档：姓名、月薪、五险一金按城市默认比例
- 个税自动算，不用自己查税率表
- 每位用户可选税前 / 税后两种口径：税后 = 扣掉个税与五险一金个人部分
- 曲线颜色按用户固定，一眼分得清是谁

【计数区间可以组合】
- 天形式：自然日 / 刨除周末 / 手动排除指定日期
- 小时形式：24 小时 / 自定义起止时间
- 两种形式自由组合，切换即时生效
- 已排除的日子不参与计算，也不会拉低平均

【曲线看趋势】
- 天 / 周 / 月 / 年四个视图
- 当前点与刻度按视图自适应，窄屏也不糊
- 切换用户不串档案，数据各归各

【截图与动图分享】
- 一键生成截图或动图
- 动图超出平台限制时自动降级，不会莫名其妙失败
- 分享走系统面板，不申请相册权限

【数据只在这台手机】
- 全部保存在本机，不联网、不统计、不申请任何权限
- 没有账号，没有云同步，没有内购与广告
- 卸载 App 后数据一并消失

本 App 的数字仅供娱乐与自我激励，不构成税务建议，也不替代工资条。实际到手金额以用人单位与当地政策为准。法定节假日不会自动排除，需要的话请在「手动排除指定日期」里自己加。
```

**字符数：约 620 / 4000**

## 9. 差异化依据（不写进商店文案，给审核对话用）

如果被问「和已有的工资秒表类 App 有什么区别」，按这三条答，每条都能在代码里指出位置：

1. **多用户 + 双口径**：`Shared/Models.swift` 的档案模型支持 ≤5 个 profile，
   每个 profile 独立选择 `TaxMode.preTax / .postTax`；税后走
   `Shared/TaxEngine.swift` 逐级累进 + 五险一金个人部分。
2. **可组合区间**：`Shared/IntervalEngine.swift` 把「天形式 × 小时形式」拆成两个
   正交维度，六组语义由 `LogicTests` 的真值表逐项断言。
3. **曲线与分享**：`Shared/CurveEngine.swift` 四视图共用一套抽稀规则；
   `Services/ShareService.swift` 截图与动图两条路径，动图超限自动降级。
