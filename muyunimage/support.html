如何获得帮助 / How to get support

  1. 点击 提交问题，用中文或英文描述你的问题。
  2. 标题请以 [牧云图片] 开头，便于我们识别。
  3. 如能提供系统版本（macOS）、App 版本、复现步骤和截图，处理会更快。

GitHub 无需付费。没有 GitHub 账号也可以先浏览已有解答；注册后即可发帖。

常见问题 / FAQ

关闭窗口后怎么再打开？

从菜单栏选择 窗口 → 显示主窗口，或点击 Dock 中的牧云图片图标。

图片会上传吗？

不会。所有编辑（含 AI 消除）都在本机完成。详见 隐私政策。

AI 消除模型下载失败？

模型来自 GitHub Releases 公开构建。网络受限时可稍后重试，或先使用「内容感知消除」（无需下载）。

消除后仍有残影？

涂抹时请完整覆盖目标，边缘可略多涂一圈；复杂背景建议改用 AI 消除，或对残留区域再消除一次。
