空中绞杀 · 隐私政策

SkyStrike — Privacy Policy · 最后更新 / Last updated: 2026-10-12

中文

空中绞杀不收集任何数据，代码里也没有一行网络代码。 这句话是可核对的：全部 30 个源文件只 import 了 Foundation、SwiftUI、UIKit、AVFoundation、StoreKit 和 Observation 六个系统框架，没有链接任何网络库；工程里没有 SPM 包、没有第三方库，框架构建阶段是空的。构建产物里搜不到 CFNetwork、Network.framework、WebKit、GameKit，未定义符号里也搜不到 URLSession 或 socket。你的星数、金币和每一局的记录只写在这台设备上。

我们处理什么、存在哪

四个键，全部在设备沙盒的偏好设置里，全部在本机读写：

键里面是什么
skystrike.save.v1进度：累计星数、金币、总击杀、总局数、总游玩时长；战役 / 无尽 / Boss Rush 三个模式各自的最高分、最远波数、最高星数、局数与通关标记；上次选的机体
skystrike.run.v1一局没打完的现场：分数、波次、用时、击杀、受伤次数、还剩的命数与火力等级、场上余下的子弹 / 敌人 / 障碍 / 道具，连随机数状态都在里面。留最多 3 天，之后失效
skystrike.sound.enabled音效开关
skystrike.intro.seen.v1开场演出看过没有

就这四个。没有别的键，也没有别的存储。 以上内容全部不会离开设备：本 App 不使用 iCloud，也不使用任何云同步。

这些内容里没有任何可以指认到人的东西：没有姓名、邮箱、电话、位置、设备标识符或广告标识符，也没有账号 ID——因为这个 App 根本没有账号。App 里没有让你输入文字的地方。

关于那份「没打完的现场」要多说一句： 它不是只活在内存里的。每次 App 退到后台都会把它写进上面那个键，所以它确实落到了磁盘上，最多留 3 天。它仍然只在这台设备上，但它比「当前这一局的临时数据」要结实一点，这里如实写出来。它也会在你打完一局、或者开新一局时被清掉。

没有文件，也没有数据库

工程里没有 FileManager 的任何调用，App 不往磁盘上写任何文件。没有 SwiftData、CoreData、Keychain、iCloud、CloudKit，也没有偏好设置之外的任何存储方式。

网络

App 进程里没有任何网络代码，它自己也从不发起网络请求。 飞行模式下全部内容可用：40 波战役、三种模式、四种机体、全部音效，都是从 App 包内读的，没有一处需要下载。

有一处必须说准：购买完整版时，App 会调用系统的 StoreKit 接口去问一句「这个 Apple ID 买过没有」。 这一问会由系统的商店进程去连 Apple 的服务器，不是由本 App 的进程去连的——App 里没有 URLSession，也没有 CFNetwork。所以准确的说法是「没有网络代码」，而不是「设备上永远不会发生网络通信」。恢复购买同理：那一步必须联网，离线时它会失败。

完整版购买

完整版是一次性内购（非消耗型），交易全程由 Apple 通过 App Store 处理。App 只向系统查询这个 Apple ID 是否已经购买，拿不到也存不下你的支付方式、账单信息或 Apple ID。购买记录保存在 Apple 那边，所以换设备后用「恢复购买」就能找回，不需要在本 App 里注册任何账号。

还有一件事要如实说明：如果商品信息拉不到（包括离线、或者商品还没在 App Store Connect 里配好），App 会临时开放全部内容。 这是刻意这么写的——宁可暂时收不到钱，也不让玩家打开是个残废版。

权限

本 App 不申请任何权限。 它不读取麦克风、相机、相册、通讯录、位置、健康数据或日历，不发送通知，也不申请任何追踪许可。App 的属性列表里没有任何权限用途描述，代码里也没有 UNUserNotificationCenter 或相册相关的调用，所以 iOS 根本不会为它弹出权限询问。

声音

9 种音效全部是运行时用代码算出波形合成的，App 里没有一个音频文件。 音频会话的模式是环境音（.ambient）并明确打开了「与其他音频混合」，所以它既跟随系统静音键，也不会打断你正在听的音乐；被打断后会自动恢复。静音键拨到静音时，游戏默认不出声。它不录音，也不使用麦克风。

震动

本 App 没有任何震动反馈。 工程里 CoreHaptics、UIImpactFeedbackGenerator、UINotificationFeedbackGenerator 全部零命中。

分享：唯一一条数据出口，而且由你按下去

结算页有一个「分享战绩」按钮。点下去时，App 在本机把这一局的成绩画成一张图，连同下面这句话，一起交给系统的分享面板：

我在《空中绞杀》打出 N 分，第 M 波。

图片内容就是结算页上那几项：通关或战败、分数、模式与波次、机体、三星、击杀、受伤、存活时间、金币，页脚一行「空中绞杀 · 竖屏弹幕射击 · 完全离线」。

交给系统之后，App 就不知道也不记录你选了哪个应用。不点这个按钮，什么都不会离开设备。

另外：App 不申请相册权限，代码里也没有任何相册相关的调用。如果你在系统分享面板里选了「存储图像」，那一步是系统自己完成的，不由本 App 完成。

关于页的两个链接

设置里的「隐私政策」和「技术支持」是两条链接，点下去是把网址交给系统去用 Safari 打开，开网页的是 Safari，不是本 App。App 自己不会去取这两个页面。工程里字面上的网址就这两个。

数据删除

设置页有「重置全部进度」，点下去会清空星数、金币、最高分、累计统计与已解锁的机体，也就是把 skystrike.save.v1 删掉。

要说准的是：它不会顺手清掉另外三个键。 音效开关、开场演出标记会留着，那份「没打完的现场」也可能还在——所以重置之后，菜单里的「继续」有时还能点。这不是隐私问题（都还在这台设备上），但它跟按钮的名字不完全一致，这里如实写明。想连这三个一起清掉，删除 App 是最干净的做法。

删除 App 会清空全部四个键。

设备备份

说白了：那四个键就在 App 的偏好设置里。如果你在系统里开了 iCloud 备份或电脑备份，那份备份会包含它们，和它包含你其他 App 的数据一样。那份备份由 Apple 保管，我们碰不到它；本 App 自己不会把任何东西传到任何地方。

我们不做的事

  • 不要求注册或登录
  • 不收集姓名、邮箱、位置、设备标识符或广告标识符
  • 不接入广告、分析、崩溃上报或追踪 SDK（本 App 不含任何第三方代码，工程里没有任何依赖包）
  • 不录音，不读取麦克风、相册、通讯录、位置
  • 不发送通知，也不申请任何系统权限
  • 不使用 GameKit：没有排行榜、没有成就上报、没有云端存档
  • 不把你的数据共享给任何第三方

儿童

本 App 不收集任何人的数据，当然也不收集儿童的数据。它没有账号、没有聊天、没有用户生成内容，也没有任何在 App 内浏览网页的功能。游戏内容是虚构的太空空战，不涉及任何真实人物或真实事件。

English

SkyStrike collects no data, and there is no networking code in it. That claim is checkable: all 30 source files import six system frameworks only (Foundation, SwiftUI, UIKit, AVFoundation, StoreKit and Observation), no networking library is linked, the project has no Swift packages and no third-party libraries and its frameworks build phase is empty. The built app links no CFNetwork, no Network.framework, no WebKit and no GameKit, and its undefined symbols contain no URLSession and no socket. Your stars, coins and run history are written on this device and nowhere else.

What the app handles, and where

Four keys, all in the app sandbox's preferences, all read and written on-device:

KeyWhat is in it
skystrike.save.v1Progress: total stars, coins, total kills, total runs, total play time; best score, furthest wave, best stars, runs and cleared flag for each of Campaign, Endless and Boss Rush; the last ship you picked
skystrike.run.v1A run in progress: score, wave, elapsed time, kills, hits taken, remaining lives and firepower level, the bullets, enemies, barriers and power-ups still on the field, and the random-number state. Kept for up to 3 days, then it expires
skystrike.sound.enabledYour sound setting
skystrike.intro.seen.v1Whether you have watched the intro

That is all four. No other keys, and no other storage. None of it ever leaves the device: there is no iCloud and no cloud sync of any kind.

None of it can be tied to a person: no name, email, phone number, location, device identifier or advertising identifier, and no account ID, because the app has no accounts. There is nowhere in the app to type anything.

One clarification about that run in progress: it does not live only in memory. Every time the app goes to the background it is written to the key above, so it does reach the disk, and it stays for up to 3 days. It is still on this device alone, but it is more durable than "temporary data for the current run", so it is spelled out here. It is cleared when you finish a run or start a new one.

No files, and no database

The project makes no use of FileManager at all and the app writes no files to disk. There is no SwiftData, CoreData, Keychain, iCloud or CloudKit, and no storage mechanism beyond preferences.

Network

There is no networking code in the app process, and the app itself never makes a network request. Everything works in Airplane Mode: all 40 campaign waves, all three modes, all four ships and every sound are read from inside the app bundle; nothing is ever downloaded.

One thing has to be stated precisely: when you buy the full version, the app calls the system's StoreKit interface to ask whether this Apple ID already owns it. That question is put to Apple's servers by the system's store process, not by this app's process, which has no URLSession and no CFNetwork. So the accurate claim is "no networking code", not "no network traffic can ever occur on the device". Restore Purchases is the same: it requires a connection, and it fails when you are offline.

The full version purchase

The full version is a one-time, non-consumable purchase handled entirely by Apple through the App Store. The app only asks the system whether this Apple ID already owns it, and never sees or stores your payment method, billing details or Apple ID. The purchase record lives with Apple, so Restore Purchases brings it back on a new device with no account to create here.

One more thing, stated plainly: if the product information cannot be loaded, including offline or before the product is configured, the app temporarily unlocks everything. That is deliberate: better to briefly give the game away than to hand a player a broken demo.

Permissions

The app requests no permissions. It does not touch the microphone, camera, photo library, contacts, location, health data or calendar, it sends no notifications, and it asks for no tracking permission. The app's property list declares no usage descriptions, and there are no notification or photo-library calls in the code, so iOS has nothing to prompt you about.

Sound

All 9 sound effects are synthesized from waveforms computed in code at runtime; the app contains no audio files. The audio session runs in ambient mode with mixing with other audio explicitly enabled, so it respects the silent switch and will not interrupt music you are listening to; it also recovers after an interruption. It does not record and does not use the microphone.

Haptics

The app has no haptics at all. There are zero references to CoreHaptics, UIImpactFeedbackGenerator or UINotificationFeedbackGenerator anywhere in the project.

Sharing: the one exit, and you press the button

The result screen has a Share button. When you tap it, the app draws that run into an image on-device and hands it, along with this line, to the system share sheet:

I scored N in SkyStrike, wave M.

The image carries what the result screen carries: win or loss, score, mode and wave, ship, three stars, kills, hits taken, survival time, coins, and a footer reading "空中绞杀 · 竖屏弹幕射击 · 完全离线".

Once it is handed over, the app neither knows nor records which destination you picked. If you never tap that button, nothing leaves the device.

One more note: the app requests no photo-library permission and contains no photo-library calls. If you choose "Save Image" in the system share sheet, that step is performed by the system, not by this app.

The two links on the About card

The Privacy Policy and Support rows in Settings are links: tapping one hands the address to the system, which opens it in Safari. Safari fetches that page, not this app. The app never retrieves them itself. Those two addresses are the only literal URLs in the project.

Deletion

Settings offers Reset All Progress. It clears stars, coins, best scores, accumulated totals and unlocked ships, which means deleting skystrike.save.v1.

To be precise: it does not clear the other three keys. The sound setting and the intro flag stay, and the run in progress may stay too, so the Continue button in the menu can still work after a reset. That is not a privacy matter (all of it is still on this device), but it does not match the button's name exactly, so it is stated here. Deleting the app is the clean way to clear all three as well.

Deleting the app clears all four keys.

Device backups

Plainly: those four keys live in the app's preferences. If you have iCloud Backup or computer backups enabled, that backup includes them, the same way it includes data from your other apps. That backup is held by Apple and we cannot reach it; the app itself sends nothing anywhere.

What we do not do

  • No account or sign-in
  • No collection of name, email, location, device identifiers or advertising identifiers
  • No ads, analytics, crash reporting or tracking SDKs (the app contains no third-party code at all, and the project has no package dependencies)
  • No recording and no microphone, photos, contacts or location access
  • No notifications, and no permission requests of any kind
  • No GameKit: no leaderboards, no achievement reporting, no cloud saves
  • No sharing with third parties

Children

The app collects no one's data, children included. It has no accounts, no chat, no user-generated content and no in-app web browsing. The game is fictional space combat and refers to no real person or event.
