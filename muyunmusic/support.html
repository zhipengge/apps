遇到问题的可能性最高的三条：
① 「怎么一首歌都没有」——这是设计如此，见下方第一条；
② 歌词不滚动 / 对不齐；
③ Wi-Fi 传歌或家庭影音服务器连不上（多半是不在同一网络、没开开关，或没给本地网络权限）。 下面都有答案，看完还有问题就发邮件。

为什么 App 里没有歌？

牧云音乐除随包一首《冬日之光》外，不内置、不提供任何第三方曲库——这是设计决定，不是故障，也没有「解锁曲库」的内购。其余音乐只播放你自己导入的内容：文件、歌词都要由你自己的设备提供。

怎么把音乐导进来（六条路，任选一条）

  • 文件 App：长按音频文件 → 「用此 App 打开」→ 选牧云音乐。
  • 分享：在微信、邮件、文件等任意 App 里点分享，选「牧云音乐」。
  • 电脑数据线：连接电脑，打开 Finder / iTunes → 文件共享 → 把音乐文件夹拖进「牧云音乐」。
  • iCloud Drive：App 内选择从 iCloud 导入，走系统文件选择器。
  • Wi-Fi 传歌：见下方，适合一次传一大坨。
  • 直连地址 / 家庭影音服务器：粘贴一个你自己的音频或清单 URL，或配置自己的服务器后搜索/下载。

家庭影音服务器 / 扫码怎么用？

  • 打开「设置 → 家庭影音配置」，在「音乐服务器」里填你自己的服务器地址（例如 http://192.168.1.10:8080），或点「扫码」扫服务器首页上的二维码。
  • 填好后点「测试连接」确认服务器可达；之后搜索页会出现「在线结果」，可以流播或下载到曲库；播放页会出现分享键。
  • 第一次连接局域网服务器时，系统会询问「本地网络」权限，请允许；App 只连你填的地址，不扫描、不发现网络设备。
  • 地址留空时整块服务器功能隐藏，App 不会发出任何相关请求。
  • 扫码时系统会询问相机权限；画面只在本机识别二维码，不拍照、不保存、不上传。

Wi-Fi 传歌怎么用？

  • 手机和电脑必须连同一个 Wi-Fi（手机流量、隔离访客网络都不行）。
  • 在「设置 → 家庭影音配置 → 启用 Wi-Fi 传输」里手动打开（默认关闭）。
  • 打开后页面会显示一个本机地址（形如 http://192.168.x.x:端口），在电脑浏览器里打开它，拖文件进去上传。
  • 传完记得把开关关掉。若系统询问本地网络权限，允许即可；App 不通过 Bonjour 广播，也不连外网。

歌词不滚动 / 对不齐？

  • 歌词可以是同文件夹下的 .lrc 文件（与音频同名），也可以是音频内嵌歌词。
  • 有歌词但不滚动：说明这份 lrc 没有时间戳，App 会把整页歌词显示出来——这是正常降级。
  • 整体早了或晚了：在曲库长按该曲 →「详情」→「歌词同步」里微调，按歌曲记住，不用每次调。
  • 也可以在该页修改标题/艺术家/专辑；保存后排序会按新信息更新。

锁屏 / 耳机没反应？

锁屏、控制中心、耳机线控的播放/暂停/上下曲都支持。若没反应，先确认没有在其它 App 里同时播放音频（两个 App 抢音频会话时系统会暂停其一）。

权限说明

  • 相机（可选）：只在扫码填服务器地址时使用，画面本机识别，不保存、不上传。
  • 本地网络（可选）：只在连接你填写的局域网服务器 / Wi-Fi 传歌时使用；不扫描、不发现设备。拒绝后本地播放不受影响。
  • 相册、麦克风、通讯录、位置、通知、追踪都不申请。

数据安全

所有数据都在这台手机上，App 没有账号系统；曲库、歌词、收藏、设置不会上传给开发者。只有你主动使用直连地址、Wi-Fi 传歌或自己的家庭影音服务器时，才与对应的地址交换文件/搜索词。详见隐私政策。
