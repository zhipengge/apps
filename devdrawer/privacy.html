速查抽屉 · 隐私政策

中文

速查抽屉不联网，也不保存你复制过的内容。 这两句话都是可以自己去核的：这个 App 的沙盒权限里根本不含网络权限（Config/DevDrawer.entitlements 里只有 com.apple.security.app-sandbox 这一条，没有 network.client），内核层面就不会让它发出网络请求；全部源码里也没有任何网络 API。剪贴板历史只存在内存里，App 一退出就全部消失，磁盘上不留任何东西。

我们处理什么、存在哪

数据用途位置
你复制到剪贴板里的纯文本（App 只读文本这一种类型，不读图片、文件、富文本）识别它是什么（JSON / JWT / 时间戳 / 颜色 / 正则 等 21 类），在右侧排出下一步能做什么，并按 ⌘1 把它交给对应工具仅在内存，最多 40 条，单条超过 1 MB 不入历史，App 退出即清空
配置：快捷键、历史上限、面板尺寸、被禁用和被置顶的工具、是否在菜单栏显示类型角标记住你的偏好App 沙盒内的 UserDefaults，只有一个键 devdrawer.config.v1
工具参数：正则表达式、HMAC 密钥执行你当下选的那个工具仅在内存，不会被写进配置，也不落盘

上面那份配置里没有任何一条是你复制过的内容，也没有任何一条是工具的输出。这是结构性的：写盘的入口只有一个，写的就是上面那张表第二行那几个字段。

网络

App 不发起任何网络请求。 断网、飞行模式、没有 Wi-Fi 的情况下，全部 48 个工具都能正常用。这一条有两道保证：

  • 沙盒配置里没有网络权限。 没有 com.apple.security.network.client，App 就发不出网络请求，代码里即便写了也发不出去。
  • 源码里没有任何网络 API，而且 LogicTests/run.sh 每次跑测试都会扫一遍，扫到 URLSession / CFNetwork / NWConnection 之类就直接让测试失败。

所以「完全离线」在这里不是一句承诺，是沙盒里根本不存在的能力。

剪贴板

App 会读系统剪贴板，这是它工作的前提。具体是：

  • 每秒检查一次剪贴板的变更计数，计数变了才去读内容，不是一直在读。
  • 只读纯文本（NSPasteboard.general 的 .string 类型），不读图片、不读文件、不读富文本。
  • 读到的文本进入内存里的历史列表，用于类型识别、推荐排序和工具取数。
  • 写回剪贴板只在你按 ⏎ 或 ⌘⇧C 时发生，把当前结果交还给系统。

历史没有任何写盘路径：进程一退，历史全没。代价是重启后看不到昨天复制的东西；换来的是「这个 App 不可能泄露它没有的东西」。右上角菜单和 ⌘K 都可以立即清空历史。

权限

App 不申请任何系统权限，也不会弹出任何授权框。

  • 不需要辅助功能，也不需要输入监控。 全局快捷键用 Carbon 的 RegisterEventHotKey 注册，由系统代管，不需要用户去「系统设置 → 隐私与安全性」里打勾。
  • 面板内部的 ⌘1 到 ⌘9、Esc 等按键走的是本地事件监听，只看得见发给本 App 的按键。App 从不注册全局监听器。
  • 不读屏幕内容，不读其它 App 的窗口，不做任何自动化控制。
  • 不读通讯录、日历、位置、麦克风、摄像头，不读你的文件目录，不申请完全磁盘访问。

第三方

App 里没有任何第三方代码。 工程没有 SPM 依赖、没有 CocoaPods、没有内嵌框架，界面图标是系统符号，图标是自绘的。没有广告、没有分析统计、没有崩溃上报、没有追踪 SDK，也没有检查更新的联网行为。

加密

App 提供哈希与 HMAC 工具（SHA-256、SHA-512、SHA-1、MD5、CRC-32、HMAC-SHA256），用的是系统的 CryptoKit，纯粹是本地计算：输入是你当下粘贴的文本，输出显示在面板上，两者都不落盘、不联网。App 不实现自己的加密算法，不做端到端加密，不存密钥。出口合规申报为 ITSAppUsesNonExemptEncryption = NO。

我们不做的事

  • 不要求注册或登录，没有账号
  • 不发起任何网络请求，没有自建服务器，也不上传任何东西
  • 不把剪贴板内容写进磁盘、UserDefaults 或任何日志
  • 不接入广告、分析、崩溃上报或追踪 SDK
  • 不申请任何系统权限，系统不会为它弹出授权框
  • 不把你的数据共享给任何第三方（因为没有数据可以共享）

数据删除

剪贴板历史在 App 退出的那一刻就没了，不需要额外操作；也可以在菜单里选「清空历史」或按 ⌘K 立即清掉。设置页有「恢复默认设置」，会把配置恢复成初始值。删除 App 即清除全部数据，包括那份配置文件。

儿童

本 App 不收集任何人的数据，当然也不收集儿童的数据。它没有账号、没有聊天、没有用户生成内容，也没有任何联网功能。

English

DevDrawer never goes online, and it does not save what you copy. Both statements are checkable: the app's sandbox entitlements contain no network entitlement at all (Config/DevDrawer.entitlements holds only com.apple.security.app-sandbox, with no network.client), so the kernel will not let it open a connection even if the code tried; and no networking API appears anywhere in the source. Clipboard history lives in memory only and is gone the moment the app quits. Nothing about it reaches the disk.

What the app handles, and where

DataPurposeWhere
The plain text you copy to the clipboard (the app reads only the text type, never images, files or rich text)To identify what it is (JSON, JWT, timestamp, colour, regex and 17 more), rank what you can do with it on the right, and hand it to a tool when you press a shortcutIn memory only, at most 40 entries, anything over 1 MB is not kept, cleared when the app quits
Settings: hotkey, history limit, panel size, disabled and pinned tools, whether the menu bar shows a type badgeTo remember your preferencesUserDefaults in the app sandbox, under a single key devdrawer.config.v1
Tool parameters: regular expressions and HMAC keysTo run the tool you just choseIn memory only; never written into the settings file, never saved to disk

Nothing in that settings file is anything you copied, and nothing in it is tool output. That is structural: there is exactly one place that writes to disk, and it writes only the fields in the second row above.

Network

The app makes no network requests. All 48 tools work with no Wi-Fi, offline, in Airplane Mode. Two things guarantee it:

  • The sandbox grants no network access. Without com.apple.security.network.client the app cannot open a connection, even if the code contained a request.
  • There is no networking API in the source, and LogicTests/run.sh scans for one on every test run, failing outright if it finds URLSession, CFNetwork, NWConnection or similar.

So "fully offline" is not a promise here. It is a capability the sandbox does not have.

Clipboard

The app reads the system clipboard, because that is what it is for. Specifically:

  • It checks the clipboard's change counter once a second, and reads the contents only when the counter moved.
  • It reads plain text only (the .string type on NSPasteboard.general). No images, no files, no rich text.
  • What it reads goes into an in-memory history used for type detection, ranking and tool input.
  • It writes to the clipboard only when you press Return or the copy shortcut, to hand a result back to the system.

The history has no path to disk at all: quit the app and it is gone. The cost is that yesterday's copies are not there after a restart; what you get in exchange is that the app cannot leak what it does not have. You can also clear the history immediately from the menu, or with the keyboard shortcut.

Permissions

The app requests no system permissions and never shows a permission prompt.

  • No Accessibility and no Input Monitoring. The global hotkey is registered through Carbon RegisterEventHotKey, which the system brokers, so there is nothing to tick in System Settings.
  • Keys such as the in-panel shortcuts and Escape go through a local event monitor that only sees events addressed to this app. The app never registers a global monitor.
  • It does not read the screen, does not inspect other apps' windows, and performs no automation.
  • It does not touch Contacts, Calendar, Location, Microphone or Camera, does not browse your file system, and does not ask for Full Disk Access.

Third parties

The app contains no third-party code. No SPM dependencies, no CocoaPods, no embedded frameworks; interface icons are system symbols and the app icon is drawn in code. There are no ads, no analytics, no crash reporting, no tracking SDKs, and no update check that would go online.

Encryption

The app offers hashing and HMAC tools (SHA-256, SHA-512, SHA-1, MD5, CRC-32, HMAC-SHA256) built on the system's CryptoKit. These are purely local computations: the input is the text you just pasted and the output is shown in the panel, and neither is written to disk or sent anywhere. The app implements no cryptography of its own, does no end-to-end encryption, and stores no keys. Export compliance is declared as ITSAppUsesNonExemptEncryption = NO.

What we do not do

  • No account or sign-in
  • No network requests, no server of ours, no uploads of any kind
  • No clipboard content written to disk, to UserDefaults, or to any log
  • No ads, analytics, crash reporting or tracking SDKs
  • No permission requests of any kind, so the system never prompts you
  • No sharing with third parties, because there is nothing to share

Deletion

Clipboard history is gone the moment the app quits, with nothing to do; you can also clear it right away from the menu or with the keyboard shortcut. Settings offer a reset that returns the configuration to its defaults. Deleting the app removes everything, the settings file included.

Children

The app collects no one's data, children included. It has no accounts, no chat, no user-generated content, and no networking of any kind.
