中文

怎么用？

复制点什么，按快捷键（默认 ⌥⌘V）唤出面板。面板会告诉你它是什么类型，右侧排出下一步能做什么，按 ⌘1 到 ⌘9 就是结果，⏎ 把结果拿走、面板关掉。

它怎么知道我复制的是什么？

靠本机的一层识别器，认得 21 类内容：JSON、JWT、UUID、颜色、Cron 表达式、时间戳、ISO 日期、HTTP 日期、Base64、Base64URL、十六进制、URL、邮箱、IPv4、IPv6、语义化版本号、正则、数字、文件路径、代码、纯文本。识别和排序全部在本机算，不走网络。

为什么有时候推荐的不对，或者干脆只给我「常用工具」？

因为识别器只覆盖它认得的那些类型。认不出来的内容会退回按「常用工具」兜底排序——这时候它就退化成一个普通的工具抽屉，不如按类型认出来时准。另外，内容超过 64 KB 时排序会跳过试探性执行那一步，只按类型表排，推荐质量会降一点，这是为了保证排序永远是常数时间、面板不会卡。

工具是哪些？

48 个，分八组：解码 9 个（JWT 解码、JWT 过期检查、JWT 时间字段、Base64 / Base64URL / 十六进制 / URL 解码、JSON 反转义、HTML 实体反转义）、JSON 5 个（格式化、排序键、压缩、校验、时间戳字段）、时间 4 个（时间戳互转、日期转时间戳、Cron 解释、当前时间戳）、查看 6 个（颜色转换、对比度、URL 拆解、进制转换、UUID 解析、字符统计）、编码 7 个、哈希 4 个（哈希全算法、SHA-256、MD5、HMAC-SHA256）、生成 2 个（UUID v4、UUID v7）、文本 11 个（命名风格转换、正则匹配、正则解释、与剪贴板 diff、行排序、去重、去空行、修剪、反转、加行号）。

哪些工具会改掉我的内容？

48 个里 26 个是「变换」，会顶掉面板里的当前值；22 个是「查看」，只出一份报告，不动你的内容。查看类的结果不会覆盖你手上的东西。

有点工具要我填参数？

有三个：正则匹配和正则解释要填正则表达式，HMAC 要填密钥。选了这类工具，面板会展开一个输入框让你填。这些参数只留在内存里，不会写进设置文件，退出就没了。

快捷键怎么改？

在设置页里录。全局快捷键用系统的 Carbon 热键注册，不需要「辅助功能」或「输入监控」授权，也不会弹授权框。如果快捷键和别人冲突，注册会失败——换一个组合就行。

剪贴板历史会存下来吗？重启还在吗？

不存，重启就没了。 历史只在本 App 的内存里，最多 40 条（可以在设置里改到 1 到 500），单条超过 1 MB 的内容不入历史。App 一退出，历史全部消失，磁盘上不留任何痕迹。这是刻意的：与其让你三个月前复制过的一次性密码、API key 还躺在硬盘上，不如让它随进程一起消失。菜单里选「清空历史」或按 ⌘K 可以立刻清掉。

菜单栏那个角标是什么？

当前内容的类型。设置里可以关掉。

需要联网吗？需要什么权限吗？

都不需要。App 完全不联网——它的沙盒权限里连网络权限都没有申请，源码里也没有任何网络 API，断网时 48 个工具全部可用。也不申请任何系统权限：不用辅助功能，不用输入监控，不读屏幕，不读其它 App 的窗口，不读你的文件目录，系统不会为它弹出任何授权框。详见隐私政策。

支持哪些系统？

需要 macOS 14.0 或更高版本。这是一个菜单栏 App，不占 Dock 图标，也不会出现在程序切换器里。

面板挡住别的东西了怎么办？

Esc 关掉。面板尺寸可以在设置里改。

怎么反馈问题？

到 GitHub Issues 提交，附上系统版本、复现步骤和你复制的那段内容（如果方便的话）。

English

How do I use it

Copy something and press the hotkey (Option-Command-V by default) to bring up the panel. The panel tells you what the content is, ranks what you can do with it on the right, and a shortcut takes the result and closes the panel.

How does it know what I copied

Through an on-device detector that recognises 21 kinds of content: JSON, JWT, UUID, colour, cron expression, timestamp, ISO date, HTTP date, Base64, Base64URL, hex, URL, email, IPv4, IPv6, semantic version, regular expression, number, file path, code, and plain text. Detection and ranking both run entirely on the machine, with no network involved.

Why is the suggestion sometimes wrong, or just a generic list

Because the detector only covers the types it knows. Anything it does not recognise falls back to ranking by what you use most, and at that point it degrades into an ordinary tool drawer. Separately, past 64 KB of input the ranking skips the trial-execution step and sorts on the type table alone, which lowers the quality of the suggestion; that keeps ranking constant-time so the panel never stalls.

What are the tools

48 of them, in eight groups: 9 decoders (JWT decode, JWT expiry check, JWT time claims, Base64, Base64URL, hex, URL, JSON unescape, HTML entity unescape), 5 JSON tools (format, sort keys, minify, validate, timestamp fields), 4 time tools (timestamp conversion, date to timestamp, cron explain, current timestamp), 6 inspectors (colour conversion, contrast, URL breakdown, base conversion, UUID parse, character count), 7 encoders, 4 hash tools (all hashes, SHA-256, MD5, HMAC-SHA256), 2 generators (UUID v4 and v7), and 11 text tools (naming-case conversion, regex match, regex explain, diff against the clipboard, line sort, dedupe, drop blank lines, trim, reverse, number lines).

Which tools change what I pasted

26 of the 48 are transforms that replace the current value in the panel; the other 22 are inspectors that produce a report and leave your content alone. Inspecting never overwrites what you are holding.

Some tools ask me for input

Three do: regex match and regex explain ask for a pattern, and HMAC asks for a key. Choosing one of those expands an input field in the panel. Those parameters stay in memory only, are never written into the settings file, and are gone when the app quits.

How do I change the hotkey

Record a new one in Settings. The global hotkey uses the system's Carbon hotkey registration, so it needs no Accessibility or Input Monitoring grant and never raises a permission prompt. If the combination is already taken, registration fails; pick another.

Is clipboard history saved? Will it still be there after a restart

No, and it is gone on restart. History lives only in this app's memory: at most 40 entries (adjustable from 1 to 500 in Settings), and anything over 1 MB is not kept. Quit the app and the history is entirely gone, with nothing left on disk. That is deliberate: rather than leave a one-time password or an API key from months ago sitting in a file, it disappears with the process. The menu and the keyboard shortcut both clear it immediately.

What is the menu bar badge

The type of the current content. It can be turned off in Settings.

Does it need a network connection or any permissions

Neither. The app is fully offline; its sandbox does not even request network access, and there is no networking API in the source, so all 48 tools work with no connection. It also requests no system permissions: no Accessibility, no Input Monitoring, no screen reading, no window inspection, no access to your file system, and no permission prompts. See the Privacy Policy.

Which systems are supported

macOS 14.0 or later. It is a menu bar app: no Dock icon, and it does not appear in the app switcher.

The panel is covering something

Press Escape. The panel size is adjustable in Settings.

Reporting a problem

File an issue at GitHub Issues with your system version, the steps to reproduce, and the content you copied if you can share it.
