常见问题 / FAQ

启用扩展后右键菜单没有出现？

依次确认三点：系统设置「通用 → 登录项与扩展 → 文件提供程序」中「牧云右键助手」已打开（不要去「Finder」那一项，那是快捷操作）；主 App「概览」页显示「访达扩展已启用」；仍未出现时在终端执行 killall Finder 重启访达，或注销后重新登录。

为什么新建文件、在终端打开时会弹出授权面板？

App 运行在 macOS 沙盒中，这是 App Store 的安全要求。每个文件夹只需授权一次，之后该文件夹及其子文件夹都不再询问。授权记录保存在本机，可在主 App「权限管理」中随时查看或撤销。

授权会让 App 读到我的所有文件吗？

不会。授权仅限你确认的那个文件夹，且只在你主动点击菜单项时才访问。App 不扫描磁盘、不联网，详见 隐私政策。

右键菜单太长，能收起来吗？

可以。主 App「菜单设置 → 收纳进牧云右键助手子菜单」开启后全部功能收进一个子菜单；关闭则平铺在右键菜单第一级。每个功能也都能单独关掉。

「在终端中打开」支持哪些终端？

自动检测已安装的系统终端、iTerm2、Warp、Ghostty、kitty、Alacritty，在「菜单设置」中选择偏好项。所选终端若已卸载会自动回退到系统终端。

可以自定义新建文件的模板吗？

可以。主 App「新建文件模板 → 添加模板」，填写名称、扩展名和可选的初始内容。模板可开关、可排序、可删除。

启动后看不到主窗口？

这是预期行为：扩展已启用时默认静默后台运行，只显示菜单栏图标。点击菜单栏图标 →「打开牧云右键助手」即可，也可在「通用设置」中开启「启动时显示主窗口」。

卸载后会残留什么吗？

从「应用程序」删除 App，并移除 ~/Library/Group Containers 下的 7252W54VUU.com.gezhipeng0201.MuyunRight 容器目录，即可清除全部配置与授权记录。

English

MuyunRight enhances the macOS Finder context menu — new file/folder from templates, copy path, open in Terminal, move/copy to favorites. Support is provided via GitHub Issues.

  • Open a new issue with the title prefix [牧云右键助手] or [MuyunRight].
  • Include macOS version, app version, steps to reproduce, and screenshots if possible.
  • If the menu does not appear, enable the Finder extension in System Settings › Login Items & Extensions › Finder Extensions, then run killall Finder.
  • Privacy policy: privacy.html
